## מכונת הסטטוס

```
open ──(מישהו הציע עזרה)──> committed ──(המתיישב מסמן)──> delivered
```

- `open` → `committed`: אוטומטי כשנוצרת `offer` ראשונה
- `committed` → `delivered`: **רק בעל החווה** מסמן ידנית
- אפשר לחזור `committed` → `open` (העוזר נעלם)
- `delivered` הוא סופי. `delivered_at` מזין את פיד ההצלחות

## הרשאות (RLS)

| פעולה | מי |
|---|---|
| קריאת חוות **מאומתות** | כולם (גם לא מחוברים) |
| קריאת צרכים של חוות מאומתות | כולם |
| יצירת חווה | משתמש מחובר (נוצרת `verified=false`) |
| עריכת חווה | הבעלים בלבד |
| יצירת/עריכת צורך | בעל החווה בלבד |
| יצירת הצעה | **כולם, גם בלי הרשמה** |
| קריאת הצעות | בעל החווה בלבד |
| אישור חווה (`verified=true`) | אדמין בלבד |

## פרטיות — חשוב

- **טלפון של חווה נחשף רק אחרי הצעת עזרה.** לא בפיד הפתוח.
- **אין כתובות מדויקות.** רק אזור + תיאור כללי.
- **טלפון של עוזר גלוי רק לבעל החווה.**

## מה לא נכנס לבסיס הנתונים

**חסויות** יושבות ב-`public/config.json` ולא בטבלה — כדי שאפשר יהיה להעלות נותן חסות חדש בעריכת קובץ, בלי מסך ניהול ובלי deploy מחדש. ראה `DECISIONS.md`.
