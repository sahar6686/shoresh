## צבעים

```css
--paper:      #EEECE0;  /* רקע */
--card:       #FBFAF4;  /* כרטיסים */
--ink:        #23221C;  /* טקסט */
--ink-soft:   #6E6C5D;  /* טקסט משני */
--olive:      #4C5A31;  /* ראשי — חפץ */
--olive-deep: #374420;  /* כותרות, הדר */
--wheat:      #CF9526;  /* פעולה — שינוע */
--wheat-soft: #F1DEAB;
--clay:       #B0603A;  /* זמן */
--clay-soft:  #EBCFBF;
```

**צבע לכל סוג נתינה:** 📦 חפץ = זית · 🚚 שינוע = חיטה · 🖐️ זמן = חימר

## טיפוגרפיה

```html
<link href="https://fonts.googleapis.com/css2?family=Frank+Ruhl+Libre:wght@500;700;900&family=Assistant:wght@400;500;600;700;800&display=swap" rel="stylesheet">
```

- **כותרות:** Frank Ruhl Libre, משקל 900
- **גוף:** Assistant, 400–800
- **גודל בסיס:** 14–15px. משני 12–13px.

## מידות

- פינות: כרטיס 18px · כפתור 14px · תג 8–12px
- מרווח בין כרטיסים: 12px
- ריפוד כרטיס: 15px
- גובה כפתור: 14px ריפוד אנכי (≥44px סה"כ למגע)

## עקרונות

1. **RTL תמיד** — `dir="rtl"` על ה-`<html>`
2. **פשטות ברמת סבתא** — כפתורים גדולים, מעט שדות
3. **פיד ההצלחות הוא הגיבור** — הוא המנוע הרגשי, שיראה חגיגי
4. **בלי כחול** — הפלטה היא אדמה חקלאית. הכחול היחיד המותר הוא בלוגו של משק חזני, והוא יושב על כרטיס לבן שמבודד אותו.
